# ชุดบัตรคำสั่งสัญลักษณ์จริง (Printable Tangible Coding Cards)
## สำหรับกิจกรรม Active Learning ร่วมกับเกม CodeBot AR Adventure
### คำแนะนำสำหรับคุณครู:
1. คุณครูสามารถสั่งพิมพ์เอกสารหน้านี้ลงบนกระดาษ A4 (หรือกระดาษการ์ด 180-210 แกรม)
2. ตัดแบ่งตามรอยประเพื่อแจกให้นักเรียนคู่ละ 1 ชุด
3. ให้นักเรียนบทบาท **ผู้นำทาง (Navigator)** นำบัตรคำสั่งมาเรียงต่อกันบนโต๊ะจริง เพื่อทดลองอัลกอริทึมก่อน แล้วจึงให้ **ผู้ควบคุม (Driver)** ป้อนคำสั่งด้วยท่าทางหน้ากล้องเว็บแคม หรือชูการ์ดขึ้นหน้ากล้อง

### แบบพิมพ์บัตรคำสั่ง (Printable Grid Layout)

```
+---------------------------+   +---------------------------+
|                           |   |                           |

|                           |   |                           |
|        เดินหน้า 1 ก้าว     |   |         หันซ้าย 90°       |
|       (MOVE FORWARD)      |   |         (TURN LEFT)       |
|                           |   |                           |
|   [ CODEBOT MOTION CARD ] |   |   [ CODEBOT MOTION CARD ] |
+---------------------------+   +---------------------------+

+---------------------------+   +---------------------------+
|                           |   |                           |
|           ↪️              |   |           🔁2             |
|                           |   |                           |
|         หันขวา 90°        |   |    วนซ้ำ 2 ครั้ง [เดินหน้า]|
|        (TURN RIGHT)       |   |       (REPEAT 2 TIMES)    |
|                           |   |                           |
|   [ CODEBOT MOTION CARD ] |   |    [ CODEBOT LOOP CARD ]  |
+---------------------------+   +---------------------------+

+---------------------------+   +---------------------------+
|                           |   |                           |
|           🔁3             |   |           🔁4             |

|       (REPEAT 3 TIMES)    |   |       (REPEAT 4 TIMES)    |
|                           |   |                           |
|    [ CODEBOT LOOP CARD ]  |   |    [ CODEBOT LOOP CARD ]  |
+---------------------------+   +---------------------------+

+---------------------------+   +---------------------------+
|                           |   |                           |

|   [ CODEBOT ACTION CARD ] |   |    [ CODEBOT DEBUG CARD ] |
+---------------------------+   +---------------------------+
```

### กิจกรรมเสริม: "Human Robot & AR Cardboard" (Unplugged to Plugged)
1. **Unplugged Phase (10 นาทีแรก)**:
   - ให้นักเรียนจำลองตัวเป็นหุ่นยนต์ โดย Navigator หยิบบัตรการ์ดส่งให้ Driver เดินตามช่องกระเบื้องในห้องเรียนจริง
2. **Plugged AR Phase (เล่นบนคอมพิวเตอร์)**:
   - นักเรียนนำบัตรคำสั่งที่เรียงสำเร็จ มาใช้เป็นพิมพ์เขียว (Blueprint) ในการแตะส่งสัญญาณคำสั่งเข้าสู่ตัวเกม CodeBot AR
