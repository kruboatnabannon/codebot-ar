# CodeBot AR Adventure 🤖🚀
### นวัตกรรมเกม AR ผ่านกล้องเว็บแคม เพื่อพัฒนาทักษะวิทยาการคำนวณ ป.4-ป.5
**บูรณาการกระบวนการ Game-Based Learning (GBL) และ Active Learning (Pair Programming)**

**ผู้พัฒนานวัตกรรม**: นายเตชินท์ อินทมล ตำแหน่ง ครู โรงเรียนบ้านโนนป่าหว้านเชียงฮาย สังกัดสำนักงานเขตพื้นที่การศึกษาประถมศึกษาหนองบัวลำภู เขต 2  

---

## 🌟 จุดเด่นของนวัตกรรม (Key Features)

1. **ตอบโจทย์บริบทโรงเรียนไทย 100%**:
   - ใช้งานผ่านเครื่องคอมพิวเตอร์ในห้องปฏิบัติการที่มีกล้องเว็บแคมทั่วไปได้ทันที
   - นักเรียนไม่จำเป็นต้องมีสมาร์ทโฟนส่วนตัว
   - พัฒนาเป็น **Web Application (HTML5, Canvas, Web Audio API)** เปิดบน Google Chrome หรือ Microsoft Edge ได้เลย ไม่ต้องติดตั้งโปรแกรม ไม่ติดสิทธิ์ Admin หรือ Deep Freeze
2. **การมีปฏิสัมพันธ์เสมือนจริงผ่านกล้อง (Kinesthetic AR Interaction)**:
   - ตรวจจับความเคลื่อนไหวผ่านกล้องเว็บแคม (Motion-based AR Virtual Touch) นักเรียนใช้มือแตะบล็อกคำสั่งที่ลอยอยู่บนอากาศ
   - มีระบบ Touch/Click สำรองรองรับทุกสภาพแสงและการใช้งานบนจอสัมผัสหรือเมาส์
3. **ตรงตามหลักสูตรแกนกลางฯ สสวท. (มาตรฐาน ว 4.2 ป.4 และ ป.5 รวมชั้นละ 10 ด่าน)**:
   - **แทร็ก ป.4 (10 ด่าน)**: ลำดับขั้นตอน (ด่าน 1-3), การทำซ้ำและลูปหลากหลายรูปแบบ (ด่าน 4-6: ลูปสั้น x2, อุโมงค์ยาว x4, ลูปแพทเทิร์น), นักสืบแก้บั๊ก (ด่าน 7-8), การเขียนโค้ดประหยัดบล็อก (ด่าน 9), และด่านรวมพลังแชมเปี้ยน ป.4 (ด่าน 10)
   - **แทร็ก ป.5 (10 ด่าน)**: การหารูปแบบ (ด่าน 1), ลูปผสมหลายคำสั่งในบล็อกเดียว (ด่าน 2-4: ลูปก้าวเลี้ยว, บันได 3 ขั้น, เดินรอบสถานี), การตัดสินใจและเงื่อนไข If-Then กุญแจ & ประตูเลเซอร์ (ด่าน 5-6), ดีบักกิ้งตรรกะและลูปเกินรอบ (ด่าน 7-8), บูรณาการลูปผสมเงื่อนไข (ด่าน 9), และด่านมาสเตอร์จักรวาล ป.5 (ด่าน 10)
4. **องค์ประกอบ Game-Based Learning ครบครัน**:
   - **ระบบ 3 ดาว (⭐⭐⭐)**: ดาวภารกิจสำเร็จ, ดาวประสิทธิภาพโค้ด (ความสั้น/ไม่เยิ่นเย้อ), และดาวความเร็ว
   - **การ์ดความรู้ (Knowledge Cards)**: สรุปมโนทัศน์สำคัญก่อนเริ่มด่านในภาษาที่เด็ก ป.4-ป.5 เข้าใจง่าย
   - **กระดานคะแนนในห้องเรียน (Classroom Leaderboard)**: แข่งขันความเร็วและความแม่นยำเพื่อจัดอันดับ Top 10
5. **ส่งเสริมการเรียนรู้เชิงรุก (Active Learning)**:
   - โหมดคู่หู **Pair Programming (Driver & Navigator)** มีตัวจับเวลาสลับบทบาทอัตโนมัติในเกม

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: เปิดด้วยเว็บเบราว์เซอร์โดยตรง (ง่ายที่สุด)
1. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วย **Google Chrome** หรือ **Microsoft Edge**
2. กดอนุญาตการใช้งานกล้องเว็บแคม (Allow Camera Access)
3. เริ่มสนุกกับภารกิจได้ทันที!

### วิธีที่ 2: เปิดผ่าน Local Web Server (แนะนำสำหรับการทดสอบ)
หากต้องการรันผ่าน Web Server ในเครื่อง ให้เปิด Terminal ในโฟลเดอร์นี้แล้วพิมพ์:
```bash
npx serve .
# หรือใช้ python
python3 -m http.server 8000
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`
